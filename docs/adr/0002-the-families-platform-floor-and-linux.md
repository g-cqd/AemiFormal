# 0002 — The family's platform floor, and Linux

## Context

AemiJSON, AemiRegex, AemiProtobuf and AemiMarkdown use macOS 15 and the matching releases of the other Apple platforms, with Linux built in CI.
`ask` uses macOS 26 for `Span`.

## Decision

The family floor plus Linux, as a default until the owner chose. The owner chose macOS 26 plus Linux; see ADR-0010.
