# 0037 — 128-bit hash

A 128-bit hash for fingerprints (ADR-0007). `WyHash` and `XXH64` are 64-bit, and `WyHash` documents that it does not defend against keys chosen to collide: a specification is attacker-shaped input, so an unkeyed hash would let a crafted model hide states. `aemi` has had `KeyedHash` since after `4879ca7` (SipHash-1-3, 128-bit key, 64-bit output), which covers the keying; the output width is what is left. A resumed run must keep its key in the checkpoint, because the default key is random per process. `UInt128` is native and 16-byte aligned (probed).
Single consumer in this roadmap (fingerprints), so by ADR-0011 it lives in `TLC` until a second one appears; `dolly` or the interner would be the second. Written so that it can move to aemi unchanged.
**Done when** it matches published test vectors, the avalanche and collision statistics on generated keys are recorded, and it is the default for fingerprint mode.
